# DocumentDB extension for Visual Studio Code v1.2

Version 1.2 of the **DocumentDB extension for Visual Studio Code** makes collection results
easier to explore, with clearer nested-data navigation and more useful keyboard interactions.

## What's New in v1.2

### ⭐ Explore nested collection results

Browse query results in Table or Tree View. In Table View, press **Enter** or double-click an
object cell to step into its fields, then use **Level Up**, an ancestor breadcrumb, or **Root
Level** to navigate back. Tree View lets you expand and collapse fields in place, while long
Table values truncate cleanly so BSON type indicators remain visible.

Keyboard navigation keeps you in control: when Table rows are selected, the first plain
**Escape** clears the selection without moving focus; a second returns to the view picker. With
no Table selection, or in Tree View, **Escape** returns to the picker immediately. Popups retain
first use of **Escape**. After clearing a selection, press **Space** to select only the focused
row if desired.

See [Querying in Collection View](https://microsoft.github.io/vscode-documentdb/user-manual/collection-view-querying)
for details. This work was tracked in [#1101](https://github.com/microsoft/vscode-documentdb/issues/1101).

**Minimum VS Code version:** 1.123.0.
