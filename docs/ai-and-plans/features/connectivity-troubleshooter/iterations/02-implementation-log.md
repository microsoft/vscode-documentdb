Milestone B review regressions cover ambiguous credential authorities (no parser facts or probe
targets), stored-connection preparation owned by the timed `prepare` check, the error-node hint
surviving tree argument unwrapping, and scheme-less proxy parsing with host redaction. Other
credential readers keep their existing behavior. Since WI-16 connection diagnosis reads every node through
its silent diagnostic read, so Kubernetes discovery returns port-forward metadata and the tunnel is
started or reused only by `prepare` through `ConnectionReachabilityService`; an ordinary connect from the
Discovery view still sets up its own tunnel.
